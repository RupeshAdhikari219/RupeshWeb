HTML Tag Quick Reference

Below is a structured breakdown of foundational HTML elements used across web documents:

Tag Name Description
<header> Header Defines introductory content or navigation links for a page.
<nav> Navigation Contains navigation links within a document.
<main> Main Content Specifies the primary, dominant content of a document.
<section> Section Defines a standalone section of related content within a page.
<h1> to <h6> Headings Used to establish heading levels and content hierarchy.
<p> Paragraph Defines blocks of narrative text content.
<a> Anchor Creates hyperlinks to jump to other pages or sections.
<img> Image Embeds raster or vector graphic media.
<ul> / <li> Unordered List Groups itemized bullet points without sequential ranking.
<table> Table Organizes complex data into rows and columns.
